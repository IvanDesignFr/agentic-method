# Commands

Commandes slash Claude Code disponibles dans ce projet.

| Commande | Fichier | Usage |
|----------|---------|-------|
| `/discovery` | `discovery.md` | Planning complet (Brainstorm → PRD → Architecture → Stories) |
| `/auto-discovery` | `auto-discovery.md` | Planning complet en mode RALPH autonome |
| `/feature #N` | `feature.md` | Implementation feature depuis une issue GitHub |
| `/auto-feature #N` | `auto-feature.md` | Feature complete en mode autonome (RALPH) |
| `/auto-loop "prompt"` | `auto-loop.md` | Boucle autonome jusqu'a completion de la tache |
| `/cancel-ralph` | `cancel-ralph.md` | Arrete le mode RALPH |
| `/resume-ralph` | `resume-ralph.md` | Reprend une session RALPH interrompue |
| `/quick-fix "desc"` | `quick-fix.md` | Fix rapide sans workflow complet |
| `/validate` | `validate.md` | Checklist post-implementation |
| `/pr-review #N` | `pr-review.md` | Review PR (3 passes : Correctness, Readability, Performance) |
| `/refactor <file>` | `refactor.md` | Refactoring cible avec 3 passes de review |
| `/multi-mind` | `multi-mind.md` | Debat multi-agents pour valider PRD et code |
| `/status` | `status.md` | Etat du projet |
| `/docs` | `docs.md` | Generation documentation |
| `/changelog` | `changelog.md` | Generation CHANGELOG |
| `/metrics` | `metrics.md` | Dashboard metriques projet |
| `/init [template]` | `init.md` | Initialise un nouveau projet avec scaffolding |
