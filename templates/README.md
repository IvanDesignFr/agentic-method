# templates

Ready-to-copy starters for new projects.

## Contents

- `CLAUDE.md` — Base project instructions for Claude Code (adapt to your project)
- `git-hooks/` — Pre-commit and pre-push hook scripts
- `github/` — Issue templates, PR templates, GitHub Actions workflows
- `devcontainer/` — Dev container configuration

## Quick start

Copy `CLAUDE.md` to the root of your project and fill in:
- Project description and stack
- Commit message format
- Branch and deployment conventions
- GitHub label / milestone structure

> Content to be ported from Skipper in follow-up tickets.
